Final project for CS222 - Advanced Programming

Project Summary
Our project was made to provide users with an easy to use task list to help remind and motivate them to do it! 
It can also be used for expressing all of the dates stored into your mind written down, so that it all feels a little less stressful!

Run Instructions
To run project,
You run our application and are greeted by a screen that looks like this, <img width="1919" height="1076" alt="image" src="https://github.com/user-attachments/assets/290db8c8-934d-4077-a43f-ccefb55a2045" />

You then enter the task name and the time you want it done by.

Then you can choose the day, month, and year that you want that done by!

Then there should be an "Enter input" button on the left, which will enter in the task, time, and date that the user has entered into a list down below. 
You can do this as many times as you want to enter in all of the of the tasks you need to remember!

After you feel as if you are satistied with the tasks you wrote down, click the "Screenshot" button to save your task list, 
then you will have a photo safely stored in your files to look at when you need your to-do list

Finally, you can hit the clear button to remove the tasks off of your list to make another one, or to have a fresh list ready to use for next time!
